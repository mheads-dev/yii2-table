## [1.0.0] - 2026-09-17

### Added

- Added Yii2 table HTTP actions: `TableAction`, `TableConfigAction`, `TableRowsAction`, `TableExportAction`.
- Added export exception hook for `TableAction` and `TableExportAction`.
- Added `QueryDataReaderBatchReadStrategy` for batched exports from `mheads/yii2-data-db` readers.
- Added Russian README and usage guide.
